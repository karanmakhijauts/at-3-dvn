# Raw data files

Save the original, unedited downloads here with exactly these names. The app reads them automatically.
Do not edit them by hand, so every number on screen traces back to the untouched source.

| Save as | Source | Where to get it |
|---|---|---|
| owid_genai.csv | Our World in Data, estimated share of working-age adults using generative AI | https://ourworldindata.org/grapher/estimated-share-people-generative-ai.csv?v=1&csvType=full&useColumnShortNames=false |
| btos_ai.csv | US Census Bureau, Business Trends and Outlook Survey | census.gov/hfp/btos, data downloads |
| piaac.csv (optional) | OECD Survey of Adult Skills (PIAAC) 2023 | oecd.org data explorer export |

If a chart picks the wrong column, set the column names in the `COLUMNS` block near the top of `app.py`.
